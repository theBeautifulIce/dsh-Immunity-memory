# DeepSeek Harness 长期记忆插件设计文档

## 1. 概述

### 1.1 设计目标

为 DeepSeek Harness 构建一个分层的、可演化的长期记忆系统，使 AI Agent 具备：
- **稳定的角色人格**：核心特质不可变
- **自主学习能力**：在约束下自我演化
- **高效记忆检索**：快速定位相关历史信息
- **可追溯性**：所有变更可审计

### 1.2 核心原则

1. **分层权限控制**：不同层级的记忆有不同的修改权限
2. **关联追溯**：记忆层与记事本双向关联
3. **渐进式遗忘**：模拟人类记忆衰减机制
4. **可扩展性**：支持可选的向量化检索等高级功能

## 3. 分层记忆系统详细设计

### 3.0 层级总览表

| 层级 | 名称       | 修改权限         | 数据特性       | 存储方式  |
| ---- | ---------- | ---------------- | -------------- | --------- |
| L0   | Soul 层    | 不可变           | 静态、全局     | 配置文件  |
| L1   | 思想核心层 | 不可变           | 静态、有限条目 | 配置文件  |
| L2   | 思想流动层 | Agent 受约束可变 | 动态、可扩展   | 数据库    |
| L3   | 本能行为层 | 不可变           | 静态、规则集   | 配置文件  |
| L4   | 学习行为层 | Agent 可变       | 动态、持续增长 | 数据库    |
| L5   | 目标记忆层 | Agent 可变       | 动态、中期有效 | 数据库    |
| L6   | 轮转记忆层 | Agent 自动管理   | 动态、有时效性 | 数据库    |
| L7   | 情境感知层 | 会话级临时       | 易失、会话绑定 | 内存/缓存 |

```python
def check_conflict(new_thought, core_layer):
    """
    检查新思想是否与核心层冲突
    """
    # 1. 提取关键概念
    concepts = extract_concepts(new_thought.content)
    
    # 2. 与核心原则语义对比
    for principle in core_layer.principles:
        similarity = semantic_similarity(concepts, principle.content)
        if similarity < CONFLICT_THRESHOLD:  # 例如 0.3
            return False, f"与原则 {principle.id} 冲突"
    
    # 3. 检查是否存在逻辑矛盾
    if has_logical_contradiction(new_thought, core_layer):
        return False, "存在逻辑矛盾"
    
    return True, "通过"
```

**学习流程**：
```
观察/输入 → 模式识别 → 置信度评估 → 冲突检测 →
```

**验证机制**：
```python
def validate_learning(learning_item):
    """
    验证学习内容的正确性
    """
    # 1. 频率验证：多次观察到相同模式
    if learning_item.evidence_count >= EVIDENCE_THRESHOLD:
        return True, "frequency_validated"
    
    # 2. 用户确认：用户明确确认
    if has_user_confirmation(learning_item):
        return True, "user_confirmed"
    
    # 3. 一致性验证：与现有知识一致
    if is_consistent_with_existing(learning_item):
        return True, "consistency_validated"
    
    return False, "insufficient_evidence"
```

**权限**：
- ✅ Agent 可新增（需经过验证）
- ✅ Agent 可更新（更新置信度、强化次数）
- ⚠️ Agent 删除需满足条件（长期未使用 + 低置信度）

### 3.7 L6: 轮转记忆层

**定义**：短期记忆，带有自动衰减和清理机制

**数据结构**：
```json
{
  "id": "rotating_001",
  "type": "conversation_context",  // conversation_context/temporary_fact/short_term_preference
  "content": "用户刚才提到他在使用 React 18",
  "created_at": "2024-01-22T14:00:00Z",
  "last_accessed": "2024-01-22T14:15:00Z",
  "access_count": 5,
  "freshness_period": 86400,  // 保鲜期（秒），默认24小时
  "importance_score": 0.65,
  "related_events": ["event_999"],
  "triggers": [
    {
      "timestamp": "2024-01-22T14:05:00Z",
      "context": "用户询问 React 相关问题"
    }
  ],
  "metadata": {
    "auto_extend": true,  // 是否自动延长保鲜期
    "min_access_for_extend": 3  // 触发延长的最低访问次数
  }
}
```

**重要性评分算法**：
```python
def calculate_importance(memory):
    """
    计算记忆重要性（0-1）
    """
    # 1. 时间衰减
    time_factor = decay_function(
        current_time - memory.created_at,
        half_life=memory.freshness_period / 2
    )
    
    # 2. 访问频率
    frequency_factor = min(memory.access_count / 10.0, 1.0)
    
    # 3. 关联强度
    association_factor = len(memory.related_events) / 20.0
    
    # 4. 手动标记
    manual_factor = memory.metadata.get('manual_importance', 0.5)
    
    # 综合计算
    importance = (
        time_factor * 0.3 +
        frequency_factor * 0.3 +
        association_factor * 0.2 +
        manual_factor * 0.2
    )
    
    return min(importance, 1.0)
```

**清理策略**：
```python
def should_delete(memory):
    """
    判断是否应该删除记忆
    """
    # 1. 超过保鲜期 AND 重要性低
    if is_expired(memory) and memory.importance_score < 0.3:
        return True
    
    # 2. 长期未访问 AND 访问次数少
    days_since_access = (now() - memory.last_accessed).days
    if days_since_access > 7 and memory.access_count < 2:
        return True
    
    # 3. 出现错误标记
    if memory.metadata.get('has_error', False):
        return True
    
    return False
```

**自动延长保鲜期**：
- 如果记忆在保鲜期内被访问超过 `min_access_for_extend` 次，自动延长50%
- 最多延长3次，之后建议提升到学习层

**权限**：
- ✅ Agent 完全自主管理
- ✅ 自动清理
- ✅ 自动提升（高频访问的记忆可提升到学习层）

```python
def basic_search(query, layer=None, time_range=None, tags=None):
    """
    基础检索
    """
    filters = []
    
    if layer:
        filters.append(f"layer = '{layer}'")
    
    if time_range:
        filters.append(f"created_at BETWEEN '{time_range.start}' AND '{time_range.end}'")
    
    if tags:
        tag_conditions = " OR ".join([f"'{tag}' = ANY(tags)" for tag in tags])
        filters.append(f"({tag_conditions})")
    
    # 关键词搜索
    where_clause = " AND ".join(filters) if filters else "1=1"
    
    sql = f"""
        SELECT *, ts_rank(to_tsvector('english', content), plainto_tsquery('english', '{query}')) AS rank
        FROM memories
        WHERE {where_clause}
        AND to_tsvector('english', content) @@ plainto_tsquery('english', '{query}')
        ORDER BY rank DESC, last_accessed DESC
        LIMIT 20
    """
    
    return execute_query(sql)
```

```python
def find_related_memories(memory_id, depth=2, min_weight=0.5):
    """
    查找相关记忆（广度优先搜索）
    """
    visited = set()
    queue = [(memory_id, 0)]  # (节点ID, 深度)
    related = []
    
    while queue:
        current_id, current_depth = queue.pop(0)
        
        if current_id in visited or current_depth > depth:
            continue
        
        visited.add(current_id)
        
        # 获取边
        edges = get_edges(current_id)
        
        for edge in edges:
            if edge.weight >= min_weight:
                related.append({
                    "memory_id": edge.target_id,
                    "relation": edge.edge_type,
                    "weight": edge.weight,
                    "depth": current_depth + 1
                })
                queue.append((edge.target_id, current_depth + 1))
    
    return related
```

### 5.5 结果融合与排序

**融合策略**：
```python
def merge_results(vector_results, basic_results, graph_results):
    """
    融合多源检索结果
    """
    # 1. 去重
    all_results = {}
    
    for result in vector_results:
        memory_id = result['memory_id']
        all_results[memory_id] = {
            'memory_id': memory_id,
            'vector_score': result['score'],
            'basic_score': 0,
            'graph_score': 0
        }
    
    for result in basic_results:
        memory_id = result['id']
        if memory_id in all_results:
            all_results[memory_id]['basic_score'] = result['rank']
        else:
            all_results[memory_id] = {
                'memory_id': memory_id,
                'vector_score': 0,
                'basic_score': result['rank'],
                'graph_score': 0
            }
    
    for result in graph_results:
        memory_id = result['memory_id']
        if memory_id in all_results:
            all_results[memory_id]['graph_score'] = result['weight']
    
    # 2. 综合评分
    for memory_id, scores in all_results.items():
        scores['final_score'] = (
            scores['vector_score'] * 0.5 +    # 向量搜索权重50%
            scores['basic_score'] * 0.3 +     # 基础搜索权重30%
            scores['graph_score'] * 0.2       # 关系图谱权重20%
        )
    
    # 3. 排序
    sorted_results = sorted(
        all_results.values(),
        key=lambda x: x['final_score'],
        reverse=True
    )
    
    # 4. 加载完整记忆数据
    return [load_memory(r['memory_id']) for r in sorted_results[:20]]
```

### 6.2 冲突检测

**检测类型**：
1. **逻辑冲突**：两条记忆存在逻辑矛盾
2. **层级冲突**：流动层与核心层不一致
3. **事实冲突**：学习到的知识相互矛盾

**检测算法**：
```python
def detect_conflicts():
    """
    检测记忆冲突
    """
    conflicts = []
    
    # 1. 检测思想流动层与核心层的冲突
    flow_thoughts = load_layer('L2')
    core_thoughts = load_layer('L1')
    
    for thought in flow_thoughts:
        for core in core_thoughts['principles']:
            if has_semantic_contradiction(thought['content'], core['content']):
                conflicts.append({
                    'type': 'layer_conflict',
                    'layer1': 'L2',
                    'id1': thought['id'],
                    'layer2': 'L1',
                    'id2': core['id'],
                    'description': f"流动思想 {thought['id']} 与核心原则 {core['id']} 冲突"
                })
    
    # 2. 检测学习层内部冲突
    learnings = load_layer('L4')
    
    for i, l1 in enumerate(learnings):
        for l2 in learnings[i+1:]:
            if has_factual_contradiction(l1['content'], l2['content']):
                conflicts.append({
                    'type': 'learning_conflict',
                    'id1': l1['id'],
                    'id2': l2['id'],
                    'description': f"学习 {l1['id']} 与 {l2['id']} 存在事实矛盾"
                })
    
    return conflicts
```

**冲突解决策略**：
```python
def resolve_conflict(conflict):
    """
    解决冲突
    """
    if conflict['type'] == 'layer_conflict':
        # 层级冲突：优先保留核心层，删除流动层冲突内容
        delete_memory(conflict['layer1'], conflict['id1'])
        log_to_changelog(f"删除冲突的思想流动层记忆: {conflict['id1']}")
    
    elif conflict['type'] == 'learning_conflict':
        # 学习冲突：比较置信度，保留高置信度的
        l1 = load_memory(conflict['id1'])
        l2 = load_memory(conflict['id2'])
        
        if l1['confidence'] < l2['confidence']:
            delete_memory('L4', conflict['id1'])
        else:
            delete_memory('L4', conflict['id2'])
        
        # 或者都标记为"待验证"，等待用户确认
        if abs(l1['confidence'] - l2['confidence']) < 0.1:
            mark_for_user_review([conflict['id1'], conflict['id2']])
```

### 11.4 踩坑笔记与变更 diff（实现补充）

踩坑笔记不新增表，作为 `type='note' / notebook='pitfall'` 的条目写入 `memories`，正文固定为四段：
`## 现象 / ## 根因 / ## 解决办法 / ## 预防`。`memory_pitfall` 提供 record / search / check；check 在解决
新问题前检索历史条目，避免重复踩坑。

变更历史复用 `changelog`：普通审计只写 `operation / reason / triggered_by`；结构化变更额外写
`kind='change'`，把 `{operation, entity, itemId, title, layer, notebook, changed, before, after, reason}`
序列化进 `change_details`，并将层与条目 id 写入 `layer / target_id` 索引列。`diff` 按时间、实体类型、
层、条目与操作过滤，返回分页变更；普通审计与变更分别按 `auditKeep` / `diffKeep` 截断。
凭据、Cookie、Token 不写入变更快照。

## 13. 最佳实践建议

### 13.1 初始配置

1. **Soul层和核心层设计**：
   - 花时间精心设计 L0 和 L1，这是角色的基础
   - 核心原则不要超过10条，保持简洁
   - 使用清晰、无歧义的语言

2. **保鲜期设置**：
   - 一般对话内容：24小时
   - 重要讨论：7天
   - 用户偏好：30天

3. **向量搜索**：
   - 数据量 < 1万条：不启用或使用简单实现
   - 数据量 > 1万条：考虑 Chroma
   - 数据量 > 10万条：使用 Milvus

1. **定期维护**：

### 13.3 常见问题

**Q: Agent 学习了错误的知识怎么办？**
A: 
- 用户可以主动纠正，系统会更新置信度或删除错误记忆
- 定期反思会检测矛盾
- 可以设置"待审核"机制，重要学习需人工确认

**Q: 记忆会无限增长吗？**
A:
- 轮转记忆层有自动清理机制
- 学习行为层会合并重复知识
- 可以设置最大记忆数量，超过时归档旧数据

**Q: 向量搜索失败会影响系统运行吗？**
A:
- 不会，系统会自动回退到基础搜索
- 向量搜索是增强功能，不是必需功能

**Q: 如何迁移到新的 Agent 实例？**
A:
- 不可变层（L0/L1/L3）直接复制配置文件
- 可变层导出数据库，在新实例导入
- 向量索引需要重建（如果数据量大）
