# 性能报告

生成时间：2026-11-05T13:59:56.954Z

## 测试环境

- Node：v22.14.0
- V8：-
- 平台：win32-x64
- Go 服务：v0.1.0
- Rust 核心：0.1.0
- 数据集：2000 条记忆（含 200 条互相冲突的关系边）

## 结果

| 场景 | 规模 | 耗时 | 吞吐 / 分位数 |
| --- | --- | --- | --- |
| 批量导入 | 2000 条 | 968 ms | 2066 条/秒 |
| 单条写入（平均） | 200 次 | 12.60 ms | p95 15.14 ms |
| 混合检索（平均） | 100 次 | 6.49 ms | p95 8.77 ms |
| 检索（关语义） | 100 次 | 4.20 ms | p95 5.37 ms |
| 图谱 BFS（深度 2） | 50 次 | 0.49 ms | p95 0.73 ms |
| 批量余弦（Rust） | 1000 × 384 维 | 32.33 ms | 30935 对/秒 |
| 批量重要性（Rust） | 5000 条 | 10.90 ms | 458585 条/秒 |
| 批量去重（Rust） | 2000 条 | 108.72 ms | 18395 条/秒 |

## 说明

- 检索链路：Node → 本地 HTTP → Go 服务 → SQLite FTS5（bm25）+ 向量余弦 + 图谱 BFS + 三路融合。
- 批量数学（余弦 / 重要性 / 去重）由 Rust 原生核心完成；不可用时自动退回 JS。
- 单条写入包含一次 HTTP 往返与一次 SQLite WAL 事务。
- 数字随机器不同而不同，用 `node scripts/benchmark.mjs` 可复测。
